## Environment Setup

This project uses a Python virtual environment (`.venv`).

### Activate Virtual Environment

```bash
source .venv/bin/activate
```

Or run commands directly via the virtual environment:

```bash
.venv/bin/python <script.py>
.venv/bin/pytest
```
